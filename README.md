# 🎪 my-circuit-app

サーキットフェスや対バンイベントにおける、**出演者ごとの「出演ステージ」と「入場特典」をカード形式でわかりやすく確認・管理できるWebアプリケーション**です。

Google スプレッドシートを簡易データベースとして利用しており、手軽に情報更新ができるほか、Google フォームからの情報提供にも対応しています。

---

## ✨ 主な機能

- **イベント別の自動グループ化**: スプレッドシートのデータをイベントごとにまとめてカード表示
- **アコーディオン表示**: アイドル・グループ名をクリックすると「出演ステージ」と「入場特典」が開閉
- **🧹 表記揺れの自動吸収（NEW）**: 「にゅうとく」「入特」「指名」「目当て」「写メ」「生写」「ポスカ」などの表記揺れを種別分類・枚数・時間表記に正規化
- **特典種別バッジ表示（NEW）**: 指名特典/目当て特典/チェキ/写メ/生写真/動画などを色付きバッジでひと目で判別
- **終了イベントのアーカイブ（NEW）**: 開催日ベースで終了イベントを非表示化。手動フラグ・GAS自動アーカイブ（毎日トリガー可）に対応し、「過去のイベントも表示」トグルで復活も可能
- **フォーム回答の自動転記（NEW）**: 情報提供フォームの回答を正規化・id解決・重複チェック付きでシートへ自動転記（フォーム送信時トリガー対応）
- **Google フォーム連携**: ユーザーや関係者からの情報提供フォームへ直接アクセス可能
- **スプレッドシートリアルタイム同期**: GAS（Google Apps Script）を介して最新情報を自動反映

- **ビルドツール**: Vite
- **バックエンド / DB**: Google Apps Script (GAS), Google Sheets

## 🔄 データフロー

```text
情報提供フォーム / シート1 への直接入力
        │
        ▼
GAS: syncFormResponses()（フォーム送信時トリガー onFormSubmit）
        │  正規化（PerkNormalizer）＋ イベントid解決 ＋ 重複チェック
        ▼
Google スプレッドシート（シート1）
        │  終了イベントは archivePastEvents()（毎日トリガー）が自動アーカイブ
        ▼
Vue.js アプリ（GASからGET）── カード表示（種別バッジ / 開催日 / アーカイブ表示）
```

## 📋 スプレッドシート列構成

| 列名 | 説明 | 入力元 |
|---|---|---|
| `id` | イベントID（イベント単位で共有） | 自動（マスター参照） |
| `eventName` | イベント名 | 手動 / フォーム |
| `performer` | グループ名・出演者 | 手動 / フォーム |
| `stage` | 出演ステージ・会場 | 手動 / フォーム |
| `time` | 開場/開演/出演時間（例: 開場 10:00） | 手動 / フォーム（正規化） |
| `perks` | 入場特典名 | 手動 / フォーム |
| `perkType` | 特典種別（指名特典/目当て特典/整理券/チェキ/サイン/写メ/生写真/動画/ポストカード/シール/入場特典/その他） | 自動正規化 |
| `perkDetail` | 特典詳細（例: 全員1枚 / ランダム3種から1枚） | 手動 / フォーム |
| `perkCount` | 枚数（数値） | 自動抽出 |
| `xUrl` | 告知URL（Xの告知ポスト等） | 手動 / フォーム |
| `note` | 備考 | 手動 |
| `eventDate` | 開催日（YYYY-MM-DD に正規化） | 手動 / フォーム |
| `isArchived` | アーカイブフラグ（`archived` で非表示） | 手動 / `archivePastEvents()` |

> 不足している列は、GASエディタで `setupSheets()` を実行すると自動追加されます。
> `id` はイベント単位で共有（イベントマスター参照）。終了イベントは削除せず `isArchived` でアーカイブする運用を推奨（詳細は [gas/README.md](gas/README.md)）。

## 🚀 GAS（入力支援・アーカイブ）のセットアップ

詳細は **[gas/README.md](gas/README.md)** を参照してください。概要:

1. `gas/` 内のファイルをGASエディタにコピー
2. `setupSheets()` を実行（シート・列の自動作成）
3. `testNormalizer()` で正規化ロジックを動作確認（APIキー不要）
4. Webアプリとしてデプロイ（アクセス: 全員）
5. トリガー設定: `onFormSubmit`（フォーム送信時）/ `archivePastEvents`（毎日）
